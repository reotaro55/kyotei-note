# 競艇予想note 自動生成

ボートレース公式のデータから予想記事を自動で作り、DiscordでiPhoneに届けるしくみです。
アニキがやるのは **Discordからコピー → noteに貼って公開** だけ。

## 1日の流れ

| 時刻（日本時間） | 自動でやること |
|---|---|
| 6:17ごろ | 全国の出走表を取得 → 1号艇の信頼度で10〜15レースを厳選 → 事前予想（200円）を全部送信 |
| 10:17〜 | 昼開催10〜12R・ナイターの展示を監視 → 展示が出たら展示後予想（500円）を送信 |
| 22:33ごろ | 結果を取得して的中率・回収率をまとめて送信 |

展示を見て1号艇が不安なとき（展示タイム5・6位、進入でインを取られた等）は、記事を作らず「見送り推奨」の通知だけ届きます。

## Discordに届く形

1記事につき3つのメッセージが届きます。

1. 案内（価格・締切）
2. タイトル
3. 本文（無料部分 → 余白 → 有料部分）

タイトルと本文をそれぞれ **長押し →「テキストをコピー」** → noteに貼り付け。
本文は無料部分と有料部分の間に余白を入れてあるので、有料ラインがその位置に収まります。価格を設定して公開。

## 初期設定（iPhoneでOK）

### ① Discordの通知先を作る
1. Discordで自分用のサーバーを作る
2. チャンネルの設定 → 連携サービス → ウェブフック → 新しいウェブフック
3. 「ウェブフックURLをコピー」

### ② OpenAIのAPIキーを作る
1. platform.openai.com にログイン → API keys → Create new secret key
2. 支払い方法を登録（ChatGPTの月額とは別、使った分だけの従量課金）

キーがなくても動きます（その場合は決まった型の文章になります）。

### ③ GitHubに置く
1. GitHubで **Public（公開）** のリポジトリを作る
2. このフォルダの中身を入れる
3. Settings → Secrets and variables → Actions → New repository secret で2つ登録
   - `OPENAI_API_KEY` … ②のキー
   - `DISCORD_WEBHOOK_URL` … ①のURL
4. （任意）同じ画面の Variables に `OPENAI_MODEL` を登録するとモデルを変更できます

### ④ 動作確認
Actions → 「接続テスト」→ Run workflow。Discordに「テスト送信です」が届けばOK。
「朝の事前予想」も Run workflow で手動実行できます。

## 調整したいとき

数字は全部 `kyotei/config.py` にまとまっています。

- 本数：`PRE_MAX`（事前の最大）、`POST_MAX`（展示後の最大）
- 厳しさ：`PRE_MIN_SCORE` / `POST_MIN_SCORE`（上げると厳選される）
- 買い目の点数：`PRE_SECOND` / `PRE_THIRD`（事前は今 6点）、`POST_SECOND` / `POST_THIRD`（展示後は今 4点）
- 価格：`PRICE_PRE` / `PRICE_POST`

点数の付け方は `kyotei/scoring.py` の `pre_score`（出走表）と `post_score`（展示）。

## 知っておいてほしいこと

- **有料の中身はどこにも保存しません。** 公開リポジトリなのでコードは誰でも見られますが、買い目や記事本文はログにもファイルにも残さず、Discordにだけ送ります（成績集計のときは同じ計算をやり直しています）。予想ロジック自体は見える状態になる点だけ注意。
- GitHubの定時実行は混雑時に数分〜数十分遅れることがあります。そのため監視ジョブは早めに起動しています。
- GitHub Actionsは本来ソフト開発向けのサービスで、長時間の常駐的な使い方は規約上グレーです。売上が伸びてきたら、月数百円程度のクラウドサーバーに移すと安定します（コードはそのまま動きます）。
- 公式サイトの見た目が変わると取得に失敗します。その場合はDiscordにエラー通知が届きます。
- 記事には「的中を保証しない」注意書きを自動で付け、「絶対」「必ず」「確実」などの表現は自動で言い換えます。
